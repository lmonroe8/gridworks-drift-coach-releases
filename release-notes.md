## Drift Coach — Beta Version 2.0

**Build 7.9.9 · Windows / original Assetto Corsa**

### Install

- **New user:** download **Gridworks-Drift-Coach-Beta-2.0.zip**, extract it, open **START-HERE.html**, then run **Gridworks-Setup.exe**.
- **Already on 7.9.7 or 7.9.8:** download **Gridworks-Small-Update-7.9.9.zip** (about 168 KB). Finish driving, close Assetto Corsa, extract the ZIP and run **Update-Gridworks.cmd**. Keep the extracted files together.
- You need **Assetto Corsa, Content Manager, CSP and SimHub**. The app includes its own Python runtime. Stream Deck, OBS and a second display are optional.

### This build

The public GitHub beta update channel is now built in. Future supported app patches can download in the background and apply when you choose **Restart to update**. Existing unconfigured builds need the small upgrade once to learn this channel.

The package includes the main SimHub dashboard, companion dashboard, compact **360 × 108 Angle Coach** overlay, Stream Deck profile/icon pack, setup guides and individual run review. Import the compact overlay from **Dash settings → Bundled downloads** if your SimHub still has the older overlay.

Your saved profiles, setups and recorded runs stay in place. App patches cover the app, help and bundled exports; changes to installed SimHub components, game links, Stream Deck plugins or runtime may need their own installer/import.
